# The Croft Hotel - Web Platform

ASP.NET MVC hotel website and management application for **The Croft** property.

## Overview
Guest-facing hotel experience with supporting admin/content management capabilities for rooms and bookings.

## Key Features
- Hotel marketing and information pages
- Room presentation and booking-oriented flows
- Admin/content management support
- SQL Server-backed MVC structure

## Tech Stack
- **Backend:** ASP.NET MVC (C#)
- **Frontend:** Razor views, JavaScript, CSS
- **Database:** Microsoft SQL Server
- **Solution:** `Croft.sln`
- **App folder:** `Croft/`

## Getting Started
1. Open `Croft.sln` in Visual Studio
2. Configure database connection strings
3. Restore packages, build, and run
